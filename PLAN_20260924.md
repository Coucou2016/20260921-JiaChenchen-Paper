# 五、HydroEncoder 不要直接照搬 RGB EDSR

可以借用 EDSR residual block，但重新写一个干净的：

```
class HydroEncoder(nn.Module):

    def __init__(
        self,
        in_channels=2,
        width=64,
        n_blocks=8,
    ):
        super().__init__()

        self.head = nn.Conv2d(
            in_channels,
            width,
            3,
            padding=1
        )

        self.body = nn.Sequential(
            *[
                ResidualBlock(width)
                for _ in range(n_blocks)
            ]
        )

        self.tail = nn.Conv2d(
            width,
            width,
            3,
            padding=1
        )

    def forward(self, x):

        x0 = self.head(x)

        x1 = self.body(x0)
        x1 = self.tail(x1)

        return x0 + x1
```

于是：

```
[B,2,48,48]
→
[B,64,48,48]
```

# 八、不要直接预测 HR 水深，要预测 transformed residual

我认为这是这里最关键的设计之一。

先计算：

\[
h_{base}=
\text{Bilinear}(h_{LR})
\]

但是由于水深分布重尾，最好不是在原始水深空间直接做：

\[
h=h_{base}+\Delta h.
\]

建议先做：

\[
z=\log(1+h/h_0)
\]

其中：

```
h0 = 0.10 m
```

于是：

```
def depth_encode(h, h0=0.1):    return torch.log1p(h / h0)def depth_decode(z, h0=0.1):    return h0 * torch.expm1(z)
```

主网络预测：

\[
\Delta z
\]

最后：

\[
z_{pred}=z_{base}+\Delta z
\]\[
h_{pred}=h_0[\exp(z_{pred})-1].
\]

代码：

```
base_h = F.interpolate(    lr_depth,    size=(H_hr, W_hr),    mode="bilinear",    align_corners=False,)z_base = depth_encode(base_h)delta_z = self.residual_head(feat)z_pred = z_base + delta_zh_pred = depth_decode(z_pred)h_pred = torch.clamp(h_pred, min=0.0)
```

这样比直接回归 0–22 m 好得多，因为数据本身明确呈 heavy-tail。 DATASET

```
10m LR
```

然后加 conservation loss。

但你的数据不能这么干。

因为：


不是：


> learned sub-grid hydraulic redistribution

> exact conservative interpolation。

```
class ScaleEmbedding(nn.Module):    def __init__(self, out_dim=16):        super().__init__()        self.mlp = nn.Sequential(            nn.Linear(3, 32),            nn.GELU(),            nn.Linear(32, out_dim),        )    def forward(        self,        lr_res,        hr_res,    ):        ratio = lr_res / hr_res        x = torch.stack(            [                lr_res / 30.0,                hr_res / 30.0,                torch.log(ratio),            ],            dim=-1,        )        return self.mlp(x)
```

然后 broadcast 到目标 query grid。

这样模型才明确知道：

```
这是 10→2
```

还是：

```
20→5
```

还是：

```
5→2
```

而不是让网络自己从 tensor shape 猜。

SRNO 本身的关键优势就是 continuous / arbitrary-scale operator，而不是固定 PixelShuffle scale。[开放访问计算机视觉论坛](https://openaccess.thecvf.com/content/CVPR2023/html/Wei_Super-Resolution_Neural_Operator_CVPR_2023_paper.html?utm_source=chatgpt.com)

# 二十二、Flood-LDM 第二阶段不要重新生成洪水，而是只生成 residual

这部分我建议和原 Flood-LDM 做明显区分。

Flood-LDM 当前是：

```
coarse flood
+
DEM
→
latent diffusion
→
fine flood
```

其代码提供 SR3 和 latent DDPM 两套结构；latent 配置使用独立 flood VAE 和 DEM VAE。公开配置里 latent U-Net 的输入是 12 channels、输出 4 channels，并采用 1000-step linear diffusion schedule。[GitHub](https://github.com/neosunhan/flood-diff)

论文中 VAE 将：

```
512×512×1
```

压缩成：

```
64×64×4
```

同时 DEM 作为条件。[ResearchGate](https://www.researchgate.net/publication/397738613_Flood-LDM_Generalizable_Latent_Diffusion_Models_for_rapid_and_accurate_zero-shot_High-Resolution_Flood_Mapping?utm_source=chatgpt.com)

你的版本建议改成：

\[
H_{HR}^{true}
=
H_{HR}^{det}
+
R
\]

Diffusion 只学习：

\[
p(R|H_{det},G)
\]

更准确地说，在 transformed space：

\[
R_z =
z_{true} - z_{det}
\]

因此第二阶段文件：

```
models/diffusion/residual_ldm.py
```

任务变成：

```
HydroGeo-SRNO deterministic result
                 ↓
         deterministic latent
                 ↓
              condition
                 +
             geography
                 ↓
noise → residual diffusion → residual latent
                 ↓
               VAE
                 ↓
             Δ flood
```

# 二十六、完整训练主程序建议非常简单

```
def train_step(batch, model, criterion):

    batch = move_to_device(batch)

    with autocast():

        output = model(
            lr=batch["lr"],
            lr_valid=batch["lr_valid"],
            static_cont=batch["static_cont"],
            landuse=batch["landuse"],
            lr_res=batch["lr_res"],
            hr_res=batch["hr_res"],
        )

        loss_dict = criterion(
            output=output,
            target=batch["hr"],
            mask=batch["mask"],
        )

        loss = loss_dict["total"]

    scaler.scale(loss).backward()

    scaler.unscale_(optimizer)

    torch.nn.utils.clip_grad_norm_(
        model.parameters(),
        1.0,
    )

    scaler.step(optimizer)
    scaler.update()

    optimizer.zero_grad(set_to_none=True)
```

checkpoint 按：

```
val CSI@0.05
```

和：

```
val wet-cell RMSE
```

同时保存。

不要按 PSNR 保存 best model。

# 二十九、从“论文方法”角度，我会把模型最终定义成四个核心贡献

# 三十、我建议第一版就固定的主模型名称

> **HydroGeo-SRNO: Geography-Guided Arbitrary-Scale Neural Operator for Urban Flood Super-Resolution**
